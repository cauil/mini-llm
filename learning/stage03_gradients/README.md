## 本次真实结果

检查数包含状态/形状/异常预期，不能理解成130个独立数学样本。步长扫描的失准结果是观察项，不要求所有步长均满足常规差分容差。

### A：三方对照与步长

解析参考用 Python math 计算 softmax、稳定交叉熵和 `p-one_hot`，不读取 `.grad`。差分使用相同损失的数值前向，在每个参数的独立副本上加减 h；autograd 对原始 loss 张量反向传播。

5组固定单样本在 `h=1e-5` 时，差分与解析梯度的最大绝对误差为 **1.2012e-11**，满足1e-7阈值；解析与autograd也全部满足1e-10阈值。单类别样本的梯度为零，按绝对误差判定，不要求更新。

对于原课堂 `p=[0.2,0.5,0.3]`、目标春的第0分量，实际扫描为：

| h | 差分估计 | 绝对误差 | 记录状态 |
|---|---:|---:|---|
| 1e-1 | -0.799840073588 | 1.5993e-4 | 超出常规精度阈值 |
| 1e-3 | -0.799999984000 | 1.6000e-8 | 在阈值内 |
| 1e-6 | -0.799999999912 | 8.8018e-11 | 在阈值内 |
| 1e-16 | 0 | 0.8 | 扰动被舍入掉 |

最后一行中，两侧实际分数均等于基点，不能把差分0当作真实梯度0。较大的 h 有局部近似误差，过小则可能被舍入或相减损失精度；这些 h 的表现与本次输入和 dtype 有关，不保证在所有数据上相同。

### B：backward、step 与清除

`states` 顺序为 `before_forward → after_backward → after_step → after_clear → step_without_backward`。backward 保持参数，只写梯度；普通 SGD 按旧参数减学习率乘梯度更新，但不自动清 `.grad`。显式清除后 `.grad=null`，保留已更新参数；跳过 backward 再 step 不更新。

`snapshot` 转换为独立 Python 数值，保存的旧状态不会跟随后续参数原地更新。用于快照的 detach/tolist 结果不参与训练损失计算。

### C：共享行与平均

固定输入为 B=4、V=3，输入编号 `[0,1,0,0]`；第0行被三个位置共同使用。每个位置先计算自身梯度，再除以整批4个位置，按输入编号累加回参数行。

实际共享表梯度约为：

```text
[[ 0.327563862683, -0.320229140596, -0.007334722087],
 [-0.169312031331,  0.120372304463,  0.048939726868],
 [ 0.000000000000,  0.000000000000,  0.000000000000]]
```

整表差分误差最大 **8.9760e-12**，解析与autograd误差最大6.9389e-18；SGD解析更新误差最大5.5511e-17。未查询的第2行保持不变。`contributions` 保存了每个位置的标签、概率、未平均梯度和平均后的贡献，可追踪分母与参数归属。

### D：先求新贡献，再累加

两条分支均没有 step，参数相同。第一轮对 L 求导得到 g，第二轮重新前向，对2L求导的新贡献为2g；保留旧梯度得到3g，先清除得到2g。新计算图避免把旧图释放后的重复反向错误混入实验。

### E：计算图路径

本组使用 w=1.5、a=2w，实际结果：

| 情况 | w.grad | backward |
|---|---|---|
| `.item()`仅用于日志，仍对原loss求导 | 12 | 成功 |
| 保存detach结果，实际loss仍用原a | 12 | 成功 |
| 实际loss使用detach后的a | null | 预期报错 |
| 把loss.item()重包装为新叶张量 | null | 成功；新叶自身梯度为1 |
| no_grad内算a，范围外算a² | null | 预期报错 |
| no_grad内算a，范围外算a*w | 3 | 成功 |

同样的数值不保证相同求导关系。最后一种情形把a视为常量3，只通过乘法对直接输入w求导；重新包装的叶张量不恢复到原参数的历史。

只有两种完全没有可求导目标的实验预期报错；运行记录了实际 RuntimeError，不要求逐字匹配版本相关文本。非预期异常会记录为失败并令程序返回非零。

### F：学习率

从w=2、L=w²、梯度4分别出发：

| 学习率 | 新w | 新损失 |
|---:|---:|---:|
| 0.1 | 1.6 | 2.56 |
| 0.75 | -1 | 1 |
| 1.5 | -4 | 16 |

跨过最低点不必然使损失上升；过大的步长可能落到更高损失的位置。这里根据新参数重新评估损失，不仅凭梯度方向判断效果。
