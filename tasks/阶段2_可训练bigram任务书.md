## 开工前的范围与新约定

课堂已覆盖 logits、softmax、真实目标交叉熵、减最大值与稳定损失、SGD、学习率、清梯度、参数注册、训练/验证、batch 形状与共享参数。梯度的推导留到阶段 3，本期允许直接使用 autograd。

以下是本任务明确采用的工程约定：

1. **CPU 与全量 batch**：每一步都使用全部训练相邻对，B 就是全部训练预测位置数；不随机抽样或打乱。先把可追踪的最短流程做对，mini-batch 留到后续。
2. **全零初始化**：分数表初始为 0。直接查表的 bigram 各行/列会由不同输入和标签得到不同梯度，本期可以这样初始化；不要将此结论推广为多层网络都适合全零初始化。
3. **普通 SGD**：固定学习率，momentum=0、weight_decay=0。不引入其他损失项、标签平滑或梯度裁剪。
4. **张量格式**：输入 x 与标签 y 都为一维整数张量 `[B]`，使用 `torch.long`；输出为浮点 logits `[B,V]`。softmax 沿最后一维（候选维）计算；交叉熵直接接收 logits。
5. **默认运行配置**：CPU、学习率 0.3、300 次更新；记录初始化和最终结果，中间每 10 步记录一次。配置可调整，但必须保存实际值。学习率必须为有限正数；steps 为非负整数，0 可用于检查初始模型；布尔值不作为合法整数配置。

### 两种模型应怎样比较

阶段 1 的概率采用加一平滑。本期交叉熵训练没有添加这些虚拟计数，因此不能要求它收敛到阶段 1 的平滑概率。

本期另设一个所有转移都有正计数的小实验，比较训练到稳定后的概率与**未平滑经验频率**：每格真实次数除以该行真实总次数。对于直接查表、无正则的模型，这就是交叉熵目标希望拟合的条件频率。有限步训练允许误差，不要求完全相等，也不比较 logits 是否等于某个唯一答案。

公开数据中存在零计数转移，其最优概率可能趋近于 0；有限 logits 的 softmax 仍为正，不能要求有限训练把这些概率精确变成 0。训练 loss 下降不保证 val loss 下降，也不保证一定优于计数模型。

## 功能需求

### 1. 模型与参数

- 使用 `nn.Module` 管理一张 `[V,V]` 的可训练分数表，注册为 `nn.Parameter`，无其他可训练参数。不要用直接赋值计数频率或对数计数代替梯度学习。
- `forward(x)` 接收 `[B]` 输入编号，返回 `[B,V]` 原始 logits；不在 forward 中做 softmax，也不接收真实标签来改变预测。
- 模型初始化后打印并保存 `named_parameters()` 中的名称、形状、requires_grad，以及总可训练标量数。参数总数应为 V²。
- 优化器通过 `model.parameters()` 获取参数；检查分数表确实出现在优化器管理的参数对象中。不能仅凭 requires_grad=True 判断它会更新。
- 提供查询单个当前 token 的概率分布接口，保持列顺序与词表编号一致。

### 2. 最小训练流程

- 只使用 train 的 x/y，自己组织清梯度、前向、交叉熵、backward、step，不使用封装好的 Trainer。
- 每步先清梯度；训练损失取该全量 batch 所有预测位置交叉熵的平均值。
- 训练路径保持梯度连接；用于日志的数值转换与参数快照不用于替代实际训练 loss。
- 保存第一步的分数表更新前值、backward 后梯度、step 后值。快照必须是当时的独立副本，不能后来一起变成最终值。
- 参数与损失若出现 NaN/Inf，明确报错并记录步数/配置，不静默截断或宣称训练成功。
- 默认公开数据运行应有参数实际变化，最终 train 平均 NLL 小于初始化值。不要求每步严格下降，也不以“能运行”代替数值检查。
- V=1 或已处在零梯度状态的专用测试不要求参数一定变化。

### 3. 训练记录与验证

- step=0 表示尚未更新；step=k 表示完成了 k 次更新。记录点的 train/val 指标都用该时刻固定模型重新评估，避免把更新前 train loss 和更新后 val loss误当成同一时刻。
- 评估使用稳定的交叉熵或 log-softmax 计算真实目标的 NLL，不先把极小概率四舍五入成 0 再取 log。
- 分别汇总 train/val 的预测位置数、NLL 总和、平均 NLL；按全部有效位置数平均，不平均各文档的平均值。
- 评估不得调用 backward 或 step，不修改参数，通常使用 `torch.no_grad()`。保持已有梯度状态不变，不在评估中顺便清梯度。
- 验证集为零位置时，NLL 总和为 0、平均 NLL 为 null，并注明原因；不能用 0 表示平均损失。
- 保存初始化、配置的中间记录点与最终 train/val 指标；本期保存可绘图的 JSON 日志即可，曲线绘图不设为硬性要求。
- 对默认验证文档保存逐位置追踪：来源文档、输入与目标编号、该行 logits、真实目标概率、稳定计算的 NLL。极端分数下概率显示为 0 不可反过来破坏稳定 NLL；不要对正常数据隐瞒非有限数值。
- 更换 val 而保持 train 和配置相同，训练参数轨迹应不变；不按 val 调整训练数据或在验证时更新模型。

### 4. 生成与阶段 1 对照

- 模型固定后，支持非空提示词、非负新字符数、argmax/sample 两种方式。每步只查当前序列最后一个 token 的行，选择一个 token 后追加。
- argmax 并列时选择编号最小者；sample 使用独立、固定种子的随机数生成器，连续多步使用同一个生成器，不逐步重置种子。
- 输出包含原提示词，并恰好新增指定字符数；新字符数为 0 时原样返回。提示词完整编码，未知字符报错。
- 保留同一配置下 sample 的复现能力；不同种子不保证结果不同，不要求与阶段 1 或不同运行库逐字符一致。
- 在相同词表、文档划分和评估口径下，报告阶段 1 加一平滑计数模型、本期初始模型、本期最终模型的 train/val 平均 NLL。可只读导入阶段 1 实现计算基线，不改写旧输出，也不把旧结果用于不同输入。
- 不以生成文本流畅或 val 必须胜过阶段 1 作为验收条件。解释实际观察，不能改数字迎合预期。

## 工程验收

检查使用手算、独立参考表达式或不变量，不能只把实现输出与自身比较。建议数值小测试用 float64，误差约 1e-8；float32 用约 1e-5，按数值尺度说明合理容差。

1. **数据与边界**：公开数据 train=6 个位置、val=2 个位置；复核文档来源、重复文本分别贡献样本、两篇单字符文档不能拼接。空训练报错，空验证按约定返回；未知字符、重复 id、越界编号明确报错。
2. **查行与形状**：至少覆盖 V=1、2、3、5；输入 `[B]` 得到 `[B,V]`，含重复输入；B 与 V 取不同值检查，避免方阵掩盖轴错误。同一 token 在不同 batch 位置应查同一行。
3. **概率与交叉熵**：按候选维归一化，各行概率和约为 1；零 logits 的平均交叉熵为 ln(V)；用课堂外的一组非对称分数和标签独立计算目标概率与损失。
4. **平移与稳定性**：每个样本的全部 logits 同加常数，概率/损失不变；覆盖如 `[1000,1002,1001]` 的大分数，以及 `[0,-1000]`、目标为第二项的有限损失（约 1000）。测试表达式可以使用减最大值/log-sum-exp；主训练允许直接使用库交叉熵。
5. **参数与单步更新**：参数清单含分数表且总数 V²；优化器包含该对象；独立检查 backward 不改变参数，step 满足旧参数减学习率乘梯度。用一行零分数、目标第二项、学习率 0.3 的课堂数值核对。先清梯度且无额外更新来源时，未参与样本的行不变。不要要求所有行、所有配置都必须改变。
6. **数据隔离与平均方式**：评估前后参数和已有梯度不变；改变 val 不改变训练轨迹。用预测位置数不同的文档核对按总位置数平均。
7. **公开数据训练**：默认配置真实运行，初始 train/val NLL 为 ln(3)，最终 train NLL 下降，参数发生变化；完整保存 step=0、最终与中间记录。val 可升可降，如实记录。
8. **全覆盖频率实验**：用 V=2、原始转移计数为 `[[3,1],[1,3]]` 的独立短文档构造数据，每个位置只计一次，模型仍从零开始通过 SGD 学习。把最终每行概率与未平滑行频率比较，最大绝对误差不超过 0.02。可用学习率 0.3、最多 2000 步全量训练作为起始配置，保存实际配置与误差。不要直接把目标频率写进模型，也不与加一平滑概率强求一致。
9. **生成与保存**：手工核对至少两步 argmax，覆盖并列策略、长度 0、提示词检查；固定种子重复 sample 可复现。读回保存文件，核对最终参数、指标和配置与实际模型一致。

本任务有真实训练与数值正确性风险，需要上述检查；不要求为每个日志字段或无关辅助函数添加机械重复测试。
