## 1. 目标与作业关联

实现一个字符级上下文语言模型：最近 k 个 token → embedding → 按位置拼接 → Linear → ReLU → Linear → 下一 token 的 logits。用训练、生成和独立梯度对照证明它能够利用更早的上下文。

已直接提取并完整查看 `/Users/lcf/llm/大模型作业.pdf` 第 2、3 页：

- Part 2 要求 token embedding、前馈层、词表输出头和自回归采样。本期练习这些部件的计算及接口；固定窗口拼接 MLP 是教学基线，不替代最终 Transformer，也不把这个跨位置拼接结构当作 Transformer 的逐位置 FFN。
- Part 3 要求自写训练/验证流程、平均 token 交叉熵及训练结果。本期继续最小 SGD 训练，所有样本各预测一个目标，平均分母为样本数，不是 B×k。
- 本期使用 PyTorch 基础层与 autograd；不使用现成完整模型或 Trainer。正式约 0.2B 模型、BPE、attention、AdamW、调度、PPL/BPB、断点续训和 GPU 留到对应阶段。

## 2. 范围、接口与配置

- 使用现有 `/Users/lcf/.conda/envs/pytorch/bin/python`，CPU、float64；输入/目标为 torch.long。无需安装新训练框架。
- 使用 nn.Module 注册参数；可用 nn.Embedding、nn.Linear、torch.relu、稳定交叉熵、autograd、普通 SGD。
- 模型配置为词表大小 V、上下文长度 k、embedding 维度 D、隐藏宽度 H，均为正整数，布尔值不算合法整数。
- `forward(x)`：输入 `[B,k]`，返回原始 logits `[B,V]`；B≥1。标签 `[B]` 仅参与损失，不进入模型前向。
- 形状链为 `[B,k] → [B,k,D] → [B,kD] → [B,H] → [B,V]`；拼接只合并同一样本的位置/特征维，保持 token 顺序。
- 可训练参数仅为 embedding 表、两层 Linear 的权重和偏置。embedding 与输出权重不共享，便于判断未查询行的梯度。
- 保存参数名称、形状、requires_grad、总标量数，核对它们确实由优化器管理；README 给出参数总量的计算依据。
- 默认建议：k=2、D=4、H=16、seed=42、lr=0.1、1000步、每50步记录。E 用零均值、标准差0.1的正态随机初值；两层 Linear 权重可沿用 PyTorch 默认初始化，偏置设0。记录具体策略、种子及库版本。
- 普通 SGD：momentum=0、weight_decay=0；全量 train batch，每步只更新一次。允许为收敛调整种子/维度/lr/步数，保存全部尝试及选择理由，不把未实测的默认配置宣称为必然达标。
- 必须拒绝非法维度、非 long 输入、错误 rank/k、越界编号、空 batch、非有限或非正学习率、负训练步数；steps=0允许检查初始化。模型训练中出现NaN/Inf应明确失败并报告位置。

- 不使用验证标签更新参数，不随机重分配重叠窗口到train/val。

## 4. 训练、评估与生成

1. 手写清梯度、前向、平均CE、backward、step循环。forward返回logits，交叉熵直接接收logits；日志/快照不切断实际训练路径。
2. 保存初始化、最终及中间train/val loss；评估用eval/no_grad，按所有预测目标的NLL总和除以目标数，不平均文档平均值或不等长batch均值。
3. 保存第一步各参数的更新前值、backward后梯度、step后值；核对普通SGD更新式，快照必须是独立副本。JSON区分None与数值全零。
4. 默认小文本记录真实训练曲线，不要求val loss下降或优于bigram；正确性与专门的可拟合实验分别验收。
5. 生成时提示词至少含k个已知字符，每轮取当前末尾k个编号，得到分布并选择下一个字符，再追加、继续。短提示词/未知字符明确报错，不偷偷补padding。支持argmax和固定随机种子的采样，新增长度0也应有定义。
6. 保存至少两个生成样例，并逐步记录实际使用的上下文、概率和新token，验证第二步确实使用更新后的上下文。生成不读真实未来标签。
7. 保存最终state_dict、配置和词表；在新建的同配置模型上加载并比较相同输入的logits。这里仅要求模型重载，不要求优化器/采样器断点续训。

## 5. 必做正确性证据

### A. 前向、形状和查表

- one-hot矩阵乘E与索引查表数值一致；至少含重复编号和不同顺序的上下文。
- 覆盖B=1及B>1，k=1/2/3，D=1及更大，V与H不同的配置；不要求所有组合穷举，至少3组且包含一组B、k、D彼此不同，防止错误维度恰好相等而漏检。
- 逐样本前向再拼成batch，与直接batch前向一致；模型没有依赖其他样本的操作。将样本顺序重排时，输出应相同重排。
- 检查bias沿样本维广播、输出候选维为V；训练样本标签及文档边界有独立手工对照。

### B. 多层梯度独立对照

建立至少两个固定小例子：一个用于完整路径对照，一个包含batch、重复token与至少一个未使用词表行。两例ReLU输入均避开0，并覆盖正/负分支。

- 固定参数、输入、标签；逐步保存查表/拼接、第一层输出、激活、logits、概率和单样本/平均损失。
- 用课堂链式规则独立计算logits梯度、两个Linear的权重与偏置梯度、隐藏/拼接梯度和整张E梯度，再与autograd比较。解析参考不能读取autograd梯度冒充独立结果，也不能把答案写死只适配某个标签。
- 多样本时先按所定义的平均损失缩放，各位置/样本对同一embedding行的贡献相加，不按出现次数再次平均；未使用行应为0。偏置沿样本维求和，不能把权重梯度按特征维相加当作偏置梯度。
- 非叶中间量若要观察.grad，明确使用retain_grad或等价autograd接口；默认未保留的None不能用来断言梯度路径中断。该API用于观察，不改变求导数学规则。
- CPU/float64的温和小例子，前向与解析/autograd对照采用atol=1e-8、rtol=1e-6，保存最大误差与结论。接近零项看绝对误差，不在ReLU拐点验导数。
- 本期不要求重新手写中心差分；已有阶段3数值检查可作可选辅助，不能因此阻塞主线。

### C. 断梯度与初始化诊断

从同一组固定参数分别运行正确路径与隐藏层detach路径，清旧梯度后比较：前向/logits/loss、E与两层参数的梯度。用一例保证输出层有非零梯度，明确区分路径断开、梯度为0、非叶梯度未保留。保存现象与原因。

另比较正常初始化与两层权重/偏置全零的首个反向；解释哪些参数能收到非零梯度、为何不能把bigram可用的全零分数表初始化直接推广到多层网络。每个对照从独立实例开始，不污染正式训练模型。

## 6. 小实验：证明更早上下文真的有用

建立独立的固定合成词表与两篇训练文档：“我爱猫”“你爱狗”，k=2，每篇只形成一条目标样本。两个输入末字相同，前一个字不同，正确目标也不同；不跨文档串接。

- 用MLP学习这两个预测，保存两种上下文的完整分布、预测和平均CE；达到两例argmax都正确、各自目标概率均≥0.9。若默认配置未达到，先检查实现/梯度再做有记录的小规模调参，不无限训练或改写结果。
- 导入阶段2 `TrainableBigram` 新建基线，喂入同一两条样本的最后一个token及相同目标，从新初值训练并记录。不能使用阶段2默认训练器偷偷换成旧数据；也不能把原文其他相邻对加进基线改变比较对象。
- 比较两模型看到的输入信息、两种上下文的分布以及损失，说明bigram为什么无法对相同末字给出两个不同条件分布。不要把有限步结果要求成某个精确理论最优值。
- 这是小样本拟合/表达能力实验，评估这两条已见样本，不声称是独立验证集泛化。真实train/val记录来自第3节默认文档，二者明确分开。
