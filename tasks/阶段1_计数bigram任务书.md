## 已学内容与本期明确的边界

- 一个字符就是一个 token；固定词表，遇到未知字符报错。
- 行表示当前 token，列表示下一个 token；只统计同篇文档里的相邻对。
- 固定使用加一平滑，所有格子加 1 后按行归一化。保留未加一的原始计数。
- 生成支持 argmax 和按概率采样。暂不引入起止符、temperature 或 top-k。
- 评估读取真实目标的概率，用自然对数，按全部有效预测位置平均。

以下是本任务的接口约定：

1. **停止生成**：不学习结束符；输入非空提示词，生成指定数量的新字符后停止。新字符数是非负整数，0 表示原样返回提示词。
2. **随机种子**：种子用于复现伪随机抽样。同一实现、环境、模型、提示词、长度和种子应能复现结果。不同种子不保证结果一定不同，不要求跨 Python 版本生成逐字符一致。
3. **没有评估位置**：长度为 0 或 1 的文档没有相邻对；整组若没有可评估位置，平均 NLL 记为 `null` 并说明原因，不能报成 0。
4. **多篇文档的平均**：先累计所有位置的负对数概率，再除以所有位置的数量；不能直接平均长短不同文档各自的平均 NLL。

## 输入与数据归属

输入固定非空词表与已划分的文档 JSON。词表编号在本任务限定为 `0..V-1`，矩阵行列按编号排列；所有分组和生成共用同一份词表。

文档格式沿用 0C：

```json
{
  "train": [
    {"id": "train-1", "text": "春风春"},
    {"id": "train-2", "text": "春风雨"},
    {"id": "train-3", "text": "雨风春"}
  ],
  "val": [{"id": "val-1", "text": "春雨风"}]
}
```

公开词表：春=0、风=1、雨=2。不同 id 的文档可以有相同文本，分别计数；本期不要求内容去重。id 必须为非空字符串，整个输入中唯一，text 必须为字符串。空文档与空分组允许。

完整编码每篇文档，未知字符明确报错，文档错误注明 id。不要删空白、换行或未知字符，不自动扩展词表。提示词也须完整编码并检查。

**直接从完整文档枚举相邻对，不直接累计 0C 的重叠窗口输出。** 重叠窗口可能多次包含同一个原文位置；本期要求每篇文档的每个相邻位置恰好计数一次。长度 N 的文档贡献 max(0, N−1) 个位置。

## 功能需求

### 1. 拟合计数与概率

- 只用 train 文档构建 V×V 原始计数表，然后创建加一平滑的概率表。
- 验证数据不得影响计数或概率。全部训练文档为空或长度不足 2 时，原始计数全零，仍按同一平滑规则得到概率表。
- 同一个对象重新拟合时，从新输入重新统计，不把上次计数累加进去。
- 提供查询给定当前 token 的下一 token 分布的接口。

### 2. 生成

- 输入提示词、要生成的新字符数、方法（argmax 或 sample），以及采样用的整数种子。
- 每步使用当前序列的最后一个 token 查询分布，选择并追加一个 token，然后继续。
- 返回完整文本（包含原提示词）；建议同时返回 token 编号以便检查。
- argmax 取最大概率项；并列时固定取编号最小者。
- sample 按该行概率抽样；一次生成的多步应连续使用同一个随机数生成器，不在每一步重新设种子。
- 非空提示词、非负整数长度及合法方法须校验；布尔值不作为合法整数长度或种子。

### 3. 评估

- 在模型固定后分别计算 train 与 val 的指标；评估不采样，不修改词表、计数或概率。
- 对每篇文档内部的每个相邻对，用真实下一个 token 的概率计算 -ln(p)。文档首字符不单独评分，不跨文档评分。
- 返回至少：有效预测位置数、NLL 总和、平均 NLL；零位置时总和为 0、平均值为 null，并记录原因。
- 加一平滑保证合法词表中的概率为正。本期无需实现不平滑模式；若自行扩展，真实目标概率为 0 时 NLL 必须正确体现为正无穷，不能静默截成有限值。

### 4. 保存可检查结果

输出文件名可自行决定，至少保存：

- 实际词表、原始计数、平滑概率、平滑规则。
- train/val 文档 id、各文档 token 数和相邻对数、两个分组的评估指标。
- 若干生成样例及其提示词、方法、新字符数和种子。

文件可用 JSON；相同配置重复运行应覆盖本次结果，不追加旧统计。重读后能核对数值与配置。不要求单独实现加载模型后继续运行的接口。

## 工程验收

提交能重复运行的检查脚本，至少覆盖下列行为；使用手算或独立参考值，不只检查程序是否正常退出。

1. **公开数据**：原始计数与本次用户手算一致；逐行概率和为 1，各项非负；验证两个目标概率为 1/5、1/2，平均 NLL 为 -[ln(1/5)+ln(1/2)]/2。浮点值允许合理误差，例如 1e-9。
2. **新例与方向**：另选小语料，包含重复字符及至少一条非对称转移，手算关键计数和概率；核对行是当前 token，按行归一化，不能按列归一化。
3. **零行与边界**：词表包含一个没有出现在训练文本中的字符；覆盖空文档、单字符文档、空训练组与空验证组。两篇单字符文档不能拼成一个相邻对。
4. **数据隔离与状态**：改变 val 内容但保持 train 不变，计数与概率应不变；评估前后模型不变；重复拟合同一输入得到相同结果。未知字符或重复 id 明确报错。
5. **评估平均方式**：使用至少两篇有效位置数不同的文档，独立核对 NLL 总和及总位置数。不能只用等长文档验证平均逻辑。
6. **生成行为**：手算两步 argmax，覆盖并列策略；输出保留提示词并恰好新增指定字符数，长度 0 原样返回。同种子重跑 sample 结果一致；不要要求不同种子一定不同。
7. **采样分布与保存**：固定当前 token，从同一行独立抽样较多次并与理论概率比较；可使用 10000 次及每项绝对频率误差不超过 0.03，注明种子与次数。连续生成长文本的总字符频率不是这项检查的替代。保存后重读，核对表、指标、配置一致。

检查数据可以由编码 agent 设计，但用户应能解释关键验证目的。评测数值正确不等于生成文本一定通顺，本期不以句子流畅程度作为通过标准。
