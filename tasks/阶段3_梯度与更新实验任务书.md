## 实验 A：单样本梯度三方对照

对同一组原始分数、同一真实目标，计算损失和下面三份梯度：

1. **解析梯度**：按课堂手算公式，由当前 softmax 概率与真实目标构造；不得通过读取 autograd 梯度充当这份结果。
2. **中心差分**：每次只改变一个分数，其他分数固定，分别重新计算完整损失，再求两点变化率；覆盖所有候选分量。
3. **autograd 梯度**：对真实的交叉熵张量执行 backward，保存叶张量的 `.grad`。

固定测试输入（目标采用从 0 开始的编号）：

| 编号 | logits | 目标 |
|---|---|---:|
| A1 | `[0, 0, 0]` | 1 |
| A2 | `[ln(2), 0, 0]` | 2 |
| A3 | `[1, -2, 0.5]` | 0 |
| A4 | `[0.3, -0.7]` | 1 |
| A5 | `[0]` | 0 |

约束与验收：

- 损失使用稳定交叉熵或等价的稳定表达式，输入是 logits；不把 softmax 概率再次交给接收 logits 的交叉熵。
- 差分扰动必须在独立数值副本上进行，正负两次都相对于同一个基点；结束后原始参数不变，不留下累计扰动。
- 常规三方对照采用 `h=1e-5`。解析与 autograd 的最大绝对误差不超过 `1e-10`；差分与解析的最大绝对误差不超过 `1e-7`。这些阈值用于本表的温和数值与 float64，不宣称适用任意量级。
- 对接近零的梯度使用绝对误差，不用除以真实梯度的相对误差决定通过与否。
- 保存 logits、概率、标签、loss、三种梯度、实际 h、逐分量或最大绝对误差，以及明确的通过/失败结论。A5 不要求参数或概率发生变化。

### 步长观察

另取 logits=`[ln(0.2), ln(0.5), ln(0.3)]`、目标0，只观察第0个分数，扫描 `h=[1e-1, 1e-3, 1e-6, 1e-16]`。

保存每个 h 下的两侧实际分数、它们是否分别不同于基点、两侧损失、差分估计和绝对误差。解释观察到的近似误差或舍入问题；不要求所有 h 都通过常规容差，也不硬编码极小 h 的结果必须为0。步长扫描中的异常是研究对象，不能通过修改结果数字掩盖。

## 实验 B：一次更新的状态追踪

使用 A3 的初始分数与目标，把 logits 本身作为被优化的叶参数；学习率0.1，普通 SGD，`momentum=0`、`weight_decay=0`。

按顺序记录：

1. 清梯度后、前向之前的参数和梯度。
2. 计算 loss 并 backward 后的参数和梯度。
3. step 后的参数、仍保存的梯度，以及用新参数重新计算的损失。
4. 再次 `zero_grad(set_to_none=True)` 后的参数和梯度。
5. 不执行新的 backward，直接调用一次 step 后的参数和梯度。

核对 backward 不直接修改参数、第一次 step 符合普通 SGD 更新式、清梯度不修改参数、最后一步没有新梯度时不凭空更新参数。检查的是这里明确指定的优化器与状态，不扩展到其他更新规则。

快照必须保存当时的独立数值副本；不能让保存的“旧参数”随后被原地更新。JSON 中以 `null` 表示 `grad is None`，与全零向量区分。

## 实验 C：重复输入与整批平均

用阶段 2 的 `TrainableBigram` 创建新模型，设置分数表为：

```text
W = [[0.4, -0.2,  0.1],
     [0.1,  0.5, -0.4],
     [0.0,  0.0,  0.0]]
x = [0, 1, 0, 0]
y = [1, 0, 2, 1]
```

初始化指定数值时可以在 no_grad 下拷入参数；实际前向/训练损失须保持求导关系。这里 batch 大小与词表大小不同，且存在重复输入与未查询行。

- 损失对4个预测位置取平均。
- 独立构造各位置的梯度贡献，按输入编号归入同一共享参数行，保存汇总过程。
- 比较整张 `W.grad` 的解析、中心差分和 autograd 结果；差分时一次只扰动一个参数格子，使用与 A 相同的常规 h 与容差。
- 学习率0.2，记录一次普通 SGD 更新，并与解析更新比较，绝对误差不超过 `1e-10`。
- 验收重复输入影响同一参数行、分母采用全部预测位置数、未查询行本步不更新。区分 `[B,V]` 的查表输出与 `[V,V]` 的参数梯度，不能按 batch 行直接覆盖参数梯度。

## 实验 D：梯度累加与清除

两条分支都独立从 A3 的相同初始参数开始；两次 backward 之间不执行 step，每次重新前向建立新计算图。

- 分支1：先对原始交叉熵 backward；保留旧 `.grad`，重新计算交叉熵并将它乘2，再 backward。
- 分支2：先对原始交叉熵 backward；清除旧 `.grad`，重新计算交叉熵并将它乘2，再 backward。

保存每轮本应新增的梯度、实际累计 `.grad` 和参数。用独立解析梯度核对每条分支，不把“本轮贡献”与“累计槽”混为一谈；参数应保持初值。

不通过重复使用已释放的同一计算图引入无关报错，不要求 `retain_graph=True`。

## 实验 E：数值相同与求导路径不同

使用标量 `w=1.5`、`a=2*w`，每个对照重新创建 w，避免旧梯度影响判断。除第6项外，目标数值取 `a*a`。记录 w/中间量/loss 的数值、相关 `requires_grad`、w.grad，以及 backward 是否成功。

1. 正常路径：原张量计算损失并 backward；取 `.item()` 仅用于日志，仍对原 loss backward。
2. 把 `a.detach()` 保存到另一个变量，实际 loss 继续使用原 a。
3. 实际 loss 改用脱离历史的 a。
4. 用 `loss.item()` 的值新建 `requires_grad=True` 张量，只对新张量 backward；同时记录新张量自身的梯度。
5. 在 no_grad 内计算 a，范围外计算 `a*a` 并尝试 backward。
6. 在 no_grad 内计算 a，范围外计算 `a*w` 并 backward。

按实际运算路径独立判断结果并检查，不能仅用 loss 数值或“backward没报错”作为正确依据。README 解释哪些路径仍通向 w，哪些没有记录，局部常量如何参与求导。

预期会报错的实验应只捕获对应错误，保存异常类型与信息并继续其他实验；不要求匹配某个 PyTorch 版本的整句报错文字。非预期错误不得被吞掉或计为通过。

## 实验 F：学习率与实际损失变化

以 `L(w)=w²`、`w=2` 为共同起点，分别使用学习率 `[0.1, 0.75, 1.5]` 执行一次普通 SGD；每个分支独立初始化并先清梯度。

保存更新前参数/损失/梯度与更新后参数/重新计算的损失，用解析求导和更新规则核对。对照解释局部下降方向、实际步长和是否跨过最低点；不要求每个学习率都使损失下降。
